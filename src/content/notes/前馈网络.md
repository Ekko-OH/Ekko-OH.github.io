## 一句话版本

前馈网络（FNN / FFN / MLP）是 Transformer 块里的第二个子层：对每个位置**独立**地做一次「线性 → 非线性 → 线性」变换。它不负责让词与词交流，只负责把每个位置的表示变得更可算、更有表达力。

## 为什么不能只有线性层

假设没有激活函数，两层线性变换是：

$$
y = W_2(W_1 x) = (W_2 W_1)x
$$

两个矩阵相乘还是一个矩阵。堆一百层线性层，等价于一层线性层——表达力没有任何增加。语言里的「天气」和「好」之间不是线性关系，模型必须有能力弯折空间。

加上非线性之后：

$$
\operatorname{FNN}(x) = W_2\,\sigma(W_1 x + b_1) + b_2
$$

其中 $W_1 \in \mathbb{R}^{d_{ff} \times d}$，$W_2 \in \mathbb{R}^{d \times d_{ff}}$。隐藏层先把维度放大到 $d_{ff}$，激活函数逐元素作用，再压回 $d$。这就是「放大 → 激活 → 压回」。

> [!tip] 一个有用的类比
> 线性层负责「换坐标」，激活函数负责「弯折」。只有换坐标，空间永远是平的；有了弯折，才能用许多小块拼出任意复杂的边界。这就是多层网络能拟合复杂函数的最直观解释。

## position-wise 是什么意思

Transformer 里的 FNN 对序列中**每个位置分别**作用，而且所有位置共享同一组参数。写成公式：

$$
h_t = \operatorname{FNN}(x_t), \quad t = 1,\dots,n
$$

它和卷积、注意力的关键区别是：**FNN 不混合 token**。第 1 个位置的输出只依赖第 1 个位置的输入，跟第 3 个位置完全无关。让 token 之间交换信息是 Attention 的工作。

所以一个 Transformer 块可以粗略理解成两步分工：

1. **Attention**：横向混合，把其他位置的信息搬过来。
2. **FNN**：纵向变换，把搬来的信息加工得更有表达力。

## 为什么中间要放大 4 倍

原始 Transformer 取 $d_{ff} = 4d$，这个比例一直沿用至今。它不是一个理论推导出来的常数，而是一个工程折中：

- 太窄：非线性能弯折的空间不够，表达力受限。
- 太宽：参数量和计算量线性增长，收益递减。

参数量上，一层 FNN 大约是：

$$
2 \cdot d \cdot d_{ff}
$$

当 $d_{ff} = 4d$ 时是 $8d^2$。而多头注意力大约是 $4d^2$。也就是说，**FNN 占了一个 Transformer 块约三分之二的参数**。GPT-3 的 $d = 12288$，$d_{ff} = 49152$，一层 FNN 就有约 12 亿参数，96 层里很大一部分重量在这里。

| 部分 | 参数量（约） | 占比 |
| --- | --- | --- |
| 多头注意力（Q/K/V/O） | $4d^2$ | 1/3 |
| 前馈网络（$d_{ff}=4d$） | $8d^2$ | 2/3 |
| 合计 | $12d^2$ | 1 |

> [!note] 4 倍不是圣旨
> 后来的模型经常改这个比例。LLaMA 用 SwiGLU 后把 $d_{ff}$ 调到约 $\frac{8}{3}d$，让参数量和原来的 4 倍 MLP 接近；MoE 则把「一个 FNN」换成「很多个 FNN，每次只激活其中几个」。

## 激活函数：ReLU、GELU、SwiGLU

### ReLU

$$
\operatorname{ReLU}(x) = \max(0, x)
$$

便宜、稀疏、梯度简单。缺点是负半轴梯度为 0，神经元可能「死掉」。

### GELU

$$
\operatorname{GELU}(x) = x \cdot \Phi(x)
$$

其中 $\Phi$ 是标准正态分布的累积分布函数。直觉是「按输入有多大，决定让它通过多少」——不是硬切在 0，而是平滑地在 0 附近衰减。BERT、GPT-2、GPT-3 都用了 GELU。

### SwiGLU

SwiGLU 把「一个线性层 + 激活」换成「两个线性层做门控」：

$$
\operatorname{SwiGLU}(x) = \operatorname{Swish}(xW_1) \otimes (xV)
$$

$\otimes$ 是逐元素乘。一个分支负责「值」，另一个分支负责「门」，门决定值通过多少。它在同样参数量下通常比 GELU 的 MLP 效果更好，LLaMA、PaLM 等模型采用。代价是多了一个矩阵，实现和并行切分稍复杂。

## FNN 在存什么

有一种流行的解释把 FNN 看成**键值记忆**：第一层把输入映射到很多「模式」上（键），第二层把这些模式对应的内容组合起来（值）。训练时，模型把事实性知识、模板、常见搭配压进这些权重里。

这个类比能解释一些现象：模型参数量越大，能容纳的模式越多；MoE 把 FNN 拆成多个专家，相当于让不同的 FNN 记不同的知识，再由 router 按 token 选择。

但它只是直觉，不是严格结论。FNN 的每个神经元具体对应什么，仍然是可解释性研究的问题。

## MoE：把「一个 FNN」换成「很多个」

Mixture of Experts 保留 Attention 不动，把每个块里的 FNN 换成 $E$ 个专家，再加一个 router：

$$
y = \sum_{i \in \operatorname{TopK}(x)} g_i(x) \cdot \operatorname{FFN}_i(x)
$$

每个 token 只走 Top-K 个专家（常见 $K=1$ 或 $2$），所以总参数量可以很大，但每个 token 的计算量只增加一点。代价是路由要均衡、专家要能分布式放置，训练和推理都更复杂。

这解释了一个容易混淆的点：**MoE 模型的总参数量**和**每个 token 实际用到的参数量**不是一回事。宣传里的「千亿参数」通常指总参数，激活参数可能只有几分之一。

## 代码形状

```python
import torch.nn as nn

class FeedForward(nn.Module):
    def __init__(self, d_model: int, mult: float = 4.0, dropout: float = 0.0):
        super().__init__()
        hidden = int(d_model * mult)
        self.net = nn.Sequential(
            nn.Linear(d_model, hidden),
            nn.GELU(),
            nn.Linear(hidden, d_model),
            nn.Dropout(dropout),
        )

    def forward(self, x):
        # x: [batch, seq, d_model] → 每个位置独立过同一组权重
        return self.net(x)
```

SwiGLU 版本多一个门控分支：

```python
class SwiGLU(nn.Module):
    def __init__(self, d_model: int, hidden: int):
        super().__init__()
        self.gate = nn.Linear(d_model, hidden, bias=False)
        self.value = nn.Linear(d_model, hidden, bias=False)
        self.out = nn.Linear(hidden, d_model, bias=False)

    def forward(self, x):
        return self.out(nn.functional.silu(self.gate(x)) * self.value(x))
```

## 回到主线

FNN 让每个位置「算得动、拟合得了」，但它有一个刻意的限制：**不跨位置**。这正是下一步要补的：

- 让 token 之间直接交换信息 → [[注意力机制]]
- 交换信息之后，残差和归一化怎么把这一切稳定地堆起来 → [[Transformer 块]]

如果只记一句话：**FNN 是 Transformer 块里的「逐位置加工厂」，参数量的大头在这里；它负责表达力，不负责上下文。**
